Realistic handcuffs for ESX and QBCore, with animations, props, drag, headbag, tape and an ankle tracker.

Players are cuffed with animations and props, can be dragged and get a headbag or tape. The ankle tracker shows tracked players on the map for the configured jobs. Settings are managed in an in-game admin dashboard. ox_target or qb-target and pma-voice or saltychat are supported when installed.

MSK Handcuffs used to be a paid script. It is free and open source since November 2026.

## Quick start

Requires [msk_core](https://github.com/MSK-Scripts/msk_core) 4.1.0+ and [oxmysql](https://github.com/overextended/oxmysql). Download the latest [release](https://github.com/MSK-Scripts/msk_handcuffs/releases), put `msk_handcuffs` into your `resources` folder and start it after its dependencies:

```ini
ensure oxmysql
ensure msk_core
ensure msk_handcuffs
```
